# story2-format-vsix

Syntax highlighting and language support for `.story2` interactive story files.

## Features

- Syntax highlighting for `.story2` files
- Automatic language detection by file extension
- Language configuration for comments, brackets, and auto-closing pairs

## Installation

### From a .vsix file

1. Download `story2-language-0.1.0.vsix`
2. In VS Code, open the Extensions panel
3. Click the `...` menu and choose **Install from VSIX...**
4. Select the file and reload VS Code

Or from the terminal:

```bash
code --install-extension story2-language-0.1.0.vsix
```

## Usage

Open any file ending in `.story2` and the highlighting applies automatically. If it doesn't, check the language mode in the bottom-right status bar and set it to **Story2**.

## Requirements

VS Code 1.75.0 or newer.
